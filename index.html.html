Student Grade Tracker

Five students, four subjects, stored in three arrays: names[], subjects[] and the table scores[][]. Edit any mark and the results update.

Each mark is read as scores[student][subject]. The small numbers show the array index.

Student averages

Add up one row, divide by 4.

Top scorer per subject

Scan down one column, keep the best.

Read a mark by index

Direct access takes the same time for any position (O(1)).

Search by name

Linear search checks names one by one (O(n)).

Arrays are fixed-size: 5 × 4 marks.
